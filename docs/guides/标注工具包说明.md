# 乒乓球本地标注工具

组员收到视频和配套官方对象JSON后直接导入，文件可放任意目录。

从仓库 [tools/](../../tools/README.md) 下载 ZIP，进入解压后的 `pingpong-annotation-tool/` 执行下面的安装启动步骤。标准结果导出到本地仓库的 `labels/`；工具工作记录和缓存留在本机。

1. 解压整个工具包，安装64位Python 3.12。
2. 双击 **安装标注环境.cmd**，看到READY后关闭安装窗口。
3. 双击 **启动标注.cmd**，选择自己的A/B/C/D编号。
4. 点击“批量导入文件夹”，一次选择视频和配套JSON所在的目录；工具递归扫描、自动配对并加入清单。
5. 打开视频标注，按C人工确认完成，按Q/L返回列表。
6. 点击“导出结果”，选择交回目录，传回完整成员/视频/轮次目录。

触台：1、左键点球心、Enter；干扰：2—5；疑难：I/O/U；前后帧：A/D；播放：空格；放大：Z；保存：S。

视频和JSON可以分别放在所选目录的两个子文件夹，不用逐个选择；只有缺失或配对有歧义时需要重新配对。单文件导入、批量导出、目录设置和复核在“更多功能”中。复核完成前隐藏初标，完成后H对照。

工具包不含实际视频、对象JSON、模型、虚拟环境或真实标签。目前支持本项目短片、现有视频编号和官方对象JSON结构。
