# 标注工具：组员上手说明

适用Windows、64位Python 3.12，本地CPU标注，不需要GPU。

## 1. 拿到文件并启动

从仓库 [tools/](../../tools/README.md) 下载标注工具 ZIP；组长另行提供你需要标注的视频和配套官方对象JSON。A/B/C/D对应姓名由组长说明。
数据可放任意目录，不要求任务表或固定分配路径。第一版支持现有项目短视频及官方对象JSON。

1. 解压整个工具包到固定目录，进入解压得到的 `pingpong-annotation-tool/`。
2. 安装Python 3.12 x64，保留Launcher和PATH。
3. 双击“安装标注环境.cmd”，看到READY后关闭窗口；首次安装需要联网。
4. 双击“启动标注.cmd”，选择自己的成员编号和“初标”。

不要复制他人的虚拟环境。工具搬家后可能需要重建环境，先保留数据和工作记录。

## 2. 导入自己的任务

- 批量导入：主界面点击“批量导入文件夹”，一次选择包含视频和JSON的目录，自动扫描子目录并配对，不必逐个选择。
- 视频和JSON可分放在所选目录的两个子文件夹，例如videos/与annotations/。
- 单个文件：在“更多功能”中点击“单个视频＋JSON”，分别选择两份文件。
- 缺失或歧义：选中清单项，在“更多功能”中点击“重新配对”，明确选择两份文件。
- 重复编号：移除重复清单项或使用新工作目录，工具不会猜选。

双击清单项或“打开所选视频”。首次准备会顺序解码、核对实际帧数和尺寸并生成缓存。
默认工作目录为工具包内outputs/local_annotation，可在“更多功能”中另选，下次自动恢复清单与位置。
输入搬家后重新定位；哈希改变时暂停，不把旧标签套到另一份输入。

## 3. 标注并保存

|操作|作用|
|---|---|
|A/D、空格|前后帧、播放暂停|
|G、Z、B|跳帧、放大、参考框/轨迹开关|
|1＋左键＋Enter|触台：点可见球心并保存|
|2/3/4/5＋Enter|触网/触地/击球/其他，填依据，坐标可空|
|I/O/U|疑难起止帧与原因|
|选记录＋Delete/X|删除错误记录|
|K、S|清未保存草稿、保存（每15秒自动保存）|
|C|人工声明完整检查并完成|
|E|保留历史，重新编辑，取消完成|
|Q/L/Esc、N|保存返回列表、保存后尝试下一段|

不用每帧按V，也不强制显示过全部帧；仍应完整人工检查，播放进度不能代替判断。
无确定触台必须填原因；看不清记疑难。完成后冻结，修改需E；未标完也可退出或导出草稿。

## 4. 导出并交回

返回列表，点击“导出结果”，选择交回根目录；批量导出在“更多功能”中。
需要通过 GitHub 交回时，交回根目录选择本地仓库的 `labels/`。工具目录和仓库目录可以分开放置。
批量有选中项时处理选中项；未选择时处理当前成员/阶段全部已有记录。

~~~text
交回目录/A/03_007/initial/
  metadata.json
  events.jsonl
  uncertain.jsonl
  non_table_events.jsonl
~~~

传回完整成员/视频/轮次目录，保留空JSONL，不能只交events。
首次版本1，修改后自动升版本和备份；不变不重写，换交回目录也保留版本。
导出自动校验，草稿completed=false，确认完成的为true，实际显示范围另记。

新窗口输出[标准格式v2](标注文件与GitHub提交标准.md)，也能读取v1。
原session、缓存、历史及环境留在本机，不用随标准文件传输，不手改派生JSONL。

## 5. 接续与独立复核

接续自己的结果：导入同一视频和JSON，选同一成员，在“更多功能”中点击“导入结果/复核”选择自己的initial/review目录，再打开视频。
完成记录需E后修改；恢复review需提供绑定版本的完整初标包。已有工作记录不覆盖，直接打开或换工作目录。

复核别人的结果：选自己的编号，导入另一成员已完成的initial目录，工具自动进入“独立复核”。
先独立判断，完成前隐藏初标，完成后H对照；复核导出缺少来源时会带上固定初标包。
来源在本机且版本改变时显示“复核过期”，旧记录保留。重做复核请用新工作目录导入最新初标。
远端更新由组长收齐结果后校验，分歧需人工讨论，不自动升级标签。

## 6. 常见问题

|情况|处理|
|---|---|
|Python缺失|安装Python 3.12 x64，再跑安装脚本|
|找不到输入|手动配对/重新定位，两份输入均必需|
|无法完成|保存或清草稿，确认检查，无触台填原因|
|哈希或解码不符|核对数据版本，已有记录不覆盖|
|工作记录存在|直接打开恢复，或另选工作目录|
|首次准备慢或缓存大|等待解码；关闭所有窗口后可清_frames，保留成员目录|
|某段导出失败|按报告修正该段，其他成功结果已保留|

详细见[工具详细说明](标注工具详细说明.md)。先每人试一段核对口径，再批量推进。
