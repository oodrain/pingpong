# 154条视频视角对照说明

本对照表用于按赛事要求分别统计0°、45°、90°视角的Precision、Recall和F1，不修改触台标签。

## 生成方法

1. 读取`data/manifests/tasks.json`中的154条唯一`video_id`。
2. 按`video_id`前缀划分为25个来源组（00—24）；同组是同一来源和固定机位的连续回合。
3. 对每个来源组抽取第一条与最后一条视频的中间帧，确认组内机位一致。
4. 与公共15数据中目录已明确标注的0度、45度、90度画面进行视觉对照：
   - 0°：摄像机位于端线方向，球台长轴大致朝画面纵深；
   - 45°：摄像机位于球台角部，球台长轴明显斜向画面纵深；
   - 90°：摄像机位于侧面，两名运动员主要分布在画面左右两侧。
5. 将来源组视角批量展开到154条视频。

- `data/manifests/video_angles.csv`：154条逐视频映射，评估程序应读取此文件分组统计。
- `data/manifests/source_group_angles.csv`：25个来源组的映射及抽查范围。
- `development/evaluation/build_video_angle_manifest.py`：从任务清单可重复生成上述CSV。

该视角字段来自有依据的分组画面核对，不是从视频编号本身猜测。若后续取得赛事方原始视角元数据，应以赛事方元数据复核并替换。
