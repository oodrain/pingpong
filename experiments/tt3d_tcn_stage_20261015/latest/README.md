# TCN 触台识别与球检测流程：最新进展

更新日期：2026-10-17。本次在原阶段分支继续更新，当前部署入口为 [official_adapter](official_adapter/README.md)。发布范围为本项目源码、配置和汇总结果。

组员核查球检测可直接使用 [轻量桌面工具](../../../tools/ball_detection_review/README.md) 和 [工具 ZIP](../../../tools/ball_detection_review.zip)：逐帧/放大、原球框与新旧预测对照、可见性核查及独立球点定位评测。六段视频的 57 个关注帧只作开发诊断；球是否可见需人工确认，不能全部直接算模型漏检。

## 当前保留方案

视频 → 官方球检测及必要时的自动局部重检 → 自动台面几何 → 51 维轨迹与几何特征 → 逐帧 TCN → 事件解码与接触点几何复核。

TCN 保留主分支、帧率确认分支及三个固定随机种子的集成，训练与推理使用一致的填充处理。当前 C2 没有重新训练 TCN、改变阈值或更换球检测权重。原事件准入逻辑仍保留；旧 FPS 门控的非单调性尚未由一套通过全部保真验收的新方案替换。

台面在短时遮挡、部分边界不足时保留已有可信状态，遇到切镜头、明显冲突或过期则停止沿用。轨迹拟合使用真实时间戳，保留接触位置的多个可行解与不确定范围；仅在所有可行位置及邻帧观测都明显在桌外时排除触台候选。拟合不稳或几何未知时回退，不要求图像 y 速度必须先落后弹。估计接触点主要用于复核，当前输出仍沿用原自动球点及事件帧号，不能当作已验证的三维落点。

## 球检测究竟改了什么

| 内容 | 当前状态 |
|---|---|
| 官方原检测权重 | 保留；没有成功替换成精度更高的新训练模型 |
| 自动局部重检 | 可信轨迹非常稀疏时触发，只重检缺失或低置信帧，并检查响应集中度与邻帧支持；原可信球点保持不变 |
| 批处理与缓冲 | batch8、三帧拼窗及输入缓冲复用，保留原帧号和真实时间戳 |
| CUDA 输出与传输 | 仅输出原中间帧热图，I/O Binding 与 GPU 双精度坐标归约；已实现，待云端实际视频验收 |
| 分离候选、离场状态、多输出头补点 | 已做固定预算对照，未稳定改善最终事件结果，未作为当前默认替换 |
| 小检测头微调 | 出现真实球置信度下降，未采用；完整网络的困难样本微调尚未完成 |

已恢复原网络的可训练入口，并核对本地 BlurBall 检查点与官方 ONNX 的有效权重一致。因此此前两条流程的差异不能归因于独立的新预训练模型。当前尚不能声称已经解决网区、近球员漏检或背景假球。

## 当前内部事件成绩

复用 42 段开发视频、5444 帧已有自动输入与标注。其中 20 段有完整核查区间；可信窗口统计来自 42 段中的已核查部分。使用原始事件时间区间扩展 ±1 帧后的一对一匹配，以下没有 50 像素空间匹配条件。

| 范围 | TP | FP | FN | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|---:|
| 整段标注视频 | 99 | 16 | 13 | 86.09% | 88.39% | **87.22%** |
| 可信窗口 | 148 | 16 | 18 | 90.24% | 89.16% | **89.70%** |

| 视角 | 整段 TP / FP / FN | 整段 F1 | 可信窗口 F1 |
|---|---:|---:|---:|
| 0° | 22 / 9 / 6 | 74.58% | 84.44% |
| 45° | 7 / 1 / 1 | 87.50% | 93.75% |
| 90° | 70 / 6 / 6 | 92.11% | 93.25% |

F1 按合并事件计数 `2TP/(2TP+FP+FN)` 计算，不是视角平均。45°完整核查只有 8 次真实触台。数据已有多轮开发曝光，这些是内部验收成绩，不是独立盲测、官方落点评分或达到 90% 泛化能力的证明。

本轮没有重算公开样例事件成绩。早期公开成绩及固定球桌范围实验见 [历史说明](LEGACY_20261016.md)，对应不同入口和策略，不能作为当前 C2 的新成绩或与这里的内部时间 F1 直接比较。

## 工程优化与验收

- 共享同一采样帧的边缘、线段、颜色与距离图，优化真实时间戳读取，减少重复几何计算。
- 球检测批处理与台面工作线程使用有界流水线；计时覆盖补检、尾批次与线程收尾。
- C2 几何等价改动在固定画面微基准中约 1.30 倍加速。28 个真实画面的四角及质量诊断完全一致。
- 六段 671 帧的球点、可信准入和坐标一致；三个视角 231 帧从视频重新运行，11 个事件的帧号、坐标以及轨迹、特征和 TCN 分数一致。
- CPU 完整运行尚未显示整体提速。中间输出图在 CPU 较慢，因此 CPU 保留原图；CUDA 路径仍需云端等价和测速验收，尚未证明达到 50 FPS。
- 独立快速几何复核损失了一次原已命中的真实触台，当前默认关闭；没有用速度收益交换真实触台。

上述验收来自本地已完成的固定阶段；这次仓库发布不追加训练、不改阈值、不读取外折结果。
