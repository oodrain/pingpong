# TT3D 启发的台面几何与逐帧 TCN：阶段成果

> 本页保留 2026-10-15 的历史阶段结果。**2026-10-16最新进展**见 [逐帧TCN最新阶段说明](latest/README.md)，包含当前模型、公开及内部的分视角指标、固定预算评测限制和视频运行入口。下述旧31段候选标签成绩不能与新20段精确时刻评测直接相减。

日期：2026-10-15。当前已完成阶段评测，尚未接入桌面默认程序或比赛 `Solution`。

本项目结合自动球轨迹和台面几何，逐帧识别触台与击球事件。本阶段以 TCN 为事件判据，借鉴 TT3D 的台面信息与轨迹分析思路，尚未实现其完整三维轨迹重建。

## 方法与已完成工作

1. **自动台面几何**：使用台面分割、边线拟合和四角提取，修复部分截角问题；根据多帧一致性输出 `stable / held / unknown`。未知或过期几何使用缺失标记。
2. **几何核查与相机估计实验**：实现桌面四角、球网和多帧核查。在缺少内参时，按主点居中、等焦距、零畸变假设估计相机，并检查投影与时间一致性。尚不能证明所有视频均完成可靠的物理标定。
3. **轨迹分析**：保留前后轨迹拟合、帧间触台时刻修正、球台区域和方向等实验代码，用于事件分析和困难案例诊断。
4. **逐帧事件模型**：将自动球轨迹与自动台面信息转换为 27 维特征，通过 31 帧上下文独立输出触台和击球分数。两类事件可以相邻或重叠，输出不依赖旧事件候选，也不使用人工台面、球网、三维球高或球拍作为推理输入。
5. **连续监督**：整段核查替代同视频的旧窗口，未浏览和无法判断的区间使用损失掩码。训练实际覆盖 28 条视频、六个来源，共 1326 个有监督帧、75 个触台、61 个击球和 9 个其他变化。

## 数据与评测口径

154 条视频按原始录像来源分为 123 条训练视频和 31 条内部保留视频，保留来源为 `09 / 12 / 15 / 17 / 24`。另有 15 条公开样例用于开发回归。实际有监督训练来源为 `00 / 06 / 10 / 11 / 16 / 19`。

训练、归一化和参数选择均限于训练来源。采用来源留一交叉选择，最终固定为 60 轮、分数阈值 0.65、事件最小间隔 0.08 秒。网络使用 32 通道、膨胀率 1/2/4/8，随机种子为 1729。训练来源交叉选择的 F1 为 77.99%，该数值仅用于选参。

整段评测复用 46 条视频、6271 帧的自动检测结果。预测冻结后，按时间容差 ±1 帧、位置容差 50 像素进行最大匹配的一对一评分，不豁免无效参考标签附近的预测。下表仅报告本阶段 TCN 的触台结果。

## 阶段结果与分析

| 集合 | TP | FP | FN | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|---:|
| 公开样例15条 | 77 | 40 | 15 | 65.81% | 83.70% | **73.68%** |
| 内部保留31条 | 124 | 66 | 22 | 65.26% | 84.93% | **73.81%** |

总体 F1 根据合并计数计算，不是各视角 F1 的平均值。

| 视角 | 公开样例 F1 | 内部保留 F1 | 内部视频数 |
|---|---:|---:|---:|
| 0° | 69.39% | 68.38% | 15 |
| 45° | 66.67% | 76.60% | 2 |
| 90° | 86.57% | 76.80% | 14 |

当前召回率高于精确率，减少未匹配输出是主要改进方向。公开样例的 45°表现较弱；内部 45°仅有一个来源的两条视频，不能据此判断该视角已具有稳定表现。总体 F1 尚未达到 90%目标。

内部参考仍是阶段候选标签，尚非完整事件真值，因此 FP 表示未匹配输出，不能全部认定为物理误检。公开样例未参与本轮训练或阈值选择，但其失败案例曾用于开发分析；历史素材也有开发曝光。这些结果属于开发回归和内部参考，不能视为独立外部盲测。

## 源码与复现

本分支发布源码和汇总报告。模型、派生特征、训练目标、冻结预测及人工标注日志不随 Git 分发。复现需要自行准备有权使用的本地阶段包；没有该包时，训练和推理命令不能直接运行。

以下命令在仓库根目录执行。依赖版本见 `requirements-cpu.txt`，建议使用独立环境。

```bash
python -m venv .venv-stage
# Linux: source .venv-stage/bin/activate
# Windows: .venv-stage\Scripts\activate
python -m pip install -r experiments/tt3d_tcn_stage_20261015/requirements-cpu.txt

python experiments/tt3d_tcn_stage_20261015/prepare_local_bundle.py --source /path/to/local_stage_capsule
python experiments/tt3d_tcn_stage_20261015/verify_release.py
python experiments/tt3d_tcn_stage_20261015/replay.py
python experiments/tt3d_tcn_stage_20261015/train.py --cv --verify-frozen
```

本地包默认放入已忽略的 `local_bundle/`，也可用 `TT3D_TCN_BUNDLE` 指定位置。`replay.py`核对模型和输入哈希，重算分数与事件，验证冻结输出；它不运行检测器，也不代表端到端 FPS。`train.py`只读取训练数组与来源划分。完整 F1 重算另需有权使用的评测真值。

使用自己的自动检测结果：

```bash
python experiments/tt3d_tcn_stage_20261015/run_cached.py \
  --tracks /path/to/ball_tracks.jsonl \
  --geometry /path/to/geometry_samples.jsonl \
  --width 1920 --height 1080 --output /path/to/new_output
```

轨迹须逐解码帧连续编号，从 0 开始，包含实际 `timestamp_s`、`detected`、`x/y`、`confidence`、`in_image`。几何为 JSON 数组或 JSONL，包含 `frame_id / usable / valid_until / corners`；仅使用当帧及之前最新有效的几何。该入口接受检测结果，视频解码与检测尚未集成为最终入口。

外部权重不随本次发布分发。台面模型来源见 `development/detection/tt3d_segmenter.py` 与 `download_table_checkpoint.py`；可选球拍模块保留上游许可证和来源清单。
