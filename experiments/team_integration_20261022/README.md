## 原方案与C

所有有效输出对比为新增23点、丢失0点、≥1px位移2点。但“没有输出丢失”不代表“没有定位合格点退化”：16_002 f153原距球框约3.83px、C约5.77px，跨过5px合格线。新增点须逐处核查，不能自动都计为GT正确。
