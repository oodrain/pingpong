## 1. 事件模块

`event_rules.py` —— 独立单文件模块（仅标准库；启用桌面几何时需 cv2+numpy）。把 D 阶段二的全部规则改进封装为一个接口：

```python
from event_rules import detect_events

events = detect_events(trajectory, config=None, table=None)
# trajectory: 逐输入帧一条，按 input_frame_id 升序：
#   {"input_frame_id": int, "detected": bool, "x": float|None, "y": float|None,
#    "confidence": float|None}
#   达标条件：detected 且 confidence >= 0.75（与官方缓存口径一致）
# table: 可选桌面几何 {"corners": [[x,y]x4], "net": [[x,y]x2]|None}
#   corners 按标注工具规范化顺序（最左上起顺时针）；net 用于长短轴自动定向（可缺省）
# 返回: [{"frame_id": int, "x": float, "y": float}, ...]（按时间序）
#   frame_id 已含官方 fid-1 补偿（= input_frame_id - 1），不要重复补偿
```

**内部规则构成**（全部可按配置关闭，默认全开）：

1. 基础规则（沿用官方语义）：y 局部极大 + FALL≥2.0/RISE≥1.0 + MIN_GAP=10 + 帧补偿；
2. F1/F2/F3（M1.1）：强回升恢复 / 宽窗幅度 / 强候选破间隔守卫；
3. D2（M1.2）：急减速回溯修正（把迟到的极大发射修正到减速肩部）；
4. 几何门 + 图像四边形双判（需 table；双通道防"近边缘透视爆炸"误杀）；
5. D3（M1.3'）：远侧掩蔽触台检测（"上升速度浅坑"签名，0° 远半台触台）；
6. **固定范围门（v1.2）**：事件的"接触邻域"（发射帧 ±2 输入帧）内须有任一点落在桌面四边形（图像空间）± 容差内——清除"悬在台面上方、毫米投影仍贴近台面"的击球/触网类 FP。v1.1 的单点判据会误杀桌缘触点（00_001 f82-83：发射点已在桌外 20.9% 对角线，但接触邻域在桌内），故改为邻帧最小距离；需 table 才生效。

## 2. 配置

`DEFAULT_CONFIG`（= 已验证的候选栈推荐值）：

| 键 | 默认 | 含义 |
|---|---|---|
| F1 / F2 / F3 | True | M1.1 上下文特征开关 |
| D2 | True | 急减速回溯修正开关 |
| D2_back / D_smin / D_ratio / D_smax / D_dmin | 5 / 8.0 / 0.40 / 50.0 / 2 | D2 参数（回溯范围/速度下限/骤降比/速度上限/最小回溯距离） |
| gate / gate_quad | 900.0 / 4.0 | 投影门边距（mm）/ 图像四边形外扩像素；**table=None 时门自动跳过** |
| D3 / D3_ratio / D3_min | True / 0.45 / 3.0 | D3 开关与参数（骤减比/两侧最小速度） |
| range_frac / range_window / range_min_px | 0.03 / 2 / 4.0 | **固定范围门 v1.2**：接触邻域（±range_window 输入帧）内任一点到桌面四边形 ≤ max(frac×对角线, min_px) 像素即保留；`range_frac=0` 关闭；需 table（与门共用 corners） |

## 3. 调用示例

```python
# 方式一：直接读 raw/ 缓存（与 C 的轨迹包、平台离线回放一致）
import json
from event_rules import detect_events
rows = [json.loads(l) for l in open("raw/v000001.jsonl", encoding="utf-8")]
rows.sort(key=lambda r: r["input_frame_id"])
events = detect_events(rows)                       # 无几何：纯规则

# 方式二：带桌面几何（有标注的视频）
doc = json.load(open("annotations/v000001.json", encoding="utf-8"))
seg = doc["segments"][0]
events = detect_events(rows, table={"corners": seg["corners"], "net": seg.get("net")})

# 方式三：管道内逐帧调用（A 集成用）——把检测器输出整理成 trajectory 再调用即可。
# 注意在管道内要收集 FULL 视频的逐帧记录后一次性调用（规则需要前后帧）。
```

自测：`python event_rules.py <raw.jsonl> [annotations.json]` → 打印事件 JSON 与数量。

## 4. 已知边界（重要）

1. **桌面几何是可选的**：公开 15 有 D 的标注（门+双判启用的对照结果因此可得）；其余视频目前无桌面信息 → 门自动关闭（"纯规则"模式）。154 的"纯规则"对照结果见 §5。阶段三如落地自动桌面获取，把 corners 传进来即可自动恢复门的效果。
2. **候选栈状态**：本模块 = "候选栈"，规则参数在公开 15（官方 GT）上开发和留一验证；最终定稿待 C 新轨迹接入复跑（M2 四组对照）与 B 正式评估，参数如有更新会再交付一版。
3. **两处已知的 154 候选集观察项**（候选标签口径，非公开 15 现象）：
   - D2 在 90° 视角对"球员击球"（球拍处减速）与触台不可区分，可能误修正 —— 154 上 13 例、集中在 2 个来源组；
   - D3 在 154 上有 6 例额外发射（位置距任何标签 >999px，疑似未标真触台或噪声）。
   两者不影响公开 15 结果（零回归），属"待新轨迹/正式评估复验"清单。
4. **帧号约定**：输入 input_frame_id（含官方 1 帧热图滞后语义），输出 frame_id 已补偿（−1）；与 `trajectories/` 的"真实帧号"不要再做任何偏移。
5. **扫描等价性**：两遍扫描（pass1 j≤n−3、pass2 仅 j=n−2）等价官方逐帧回放——这是修复过的一个 bug（曾把已发射候选重复发射），请勿改动扫描顺序。
6. 调用需一次性传入**完整视频**的轨迹（规则依赖前后帧与间隔状态），不支持流式逐帧。
7. **固定范围门 v1.2 按团队协议复核**（重要）：单点 v1.1 在开发池的确认正例上误杀 1 例（00_001 f82-83），按协议不得以此换分。v1.2 在 9 组固定预算内、按拟合来源（01/02/04/07/08/13/18/19/21/22）完整 F1 选出 **window ±2 / 容差 3%**，内层来源（00/11/16）验证成立：完整 0.783→0.818、可信 0.667→0.694，**625 条确认正例 502/502 零丢失**。31 段保留集与 15 段公开未用于选型；公开 15 仅作工程回归（GT 角点 77/30/15 = 0.774；自动角点 76/30/16 = 0.768，丢 1 例于 v000117——自动角点误差 69px，属几何质量限制）。几何不可靠时按既有守卫传 `table=None`（门与范围门一并关闭）。
