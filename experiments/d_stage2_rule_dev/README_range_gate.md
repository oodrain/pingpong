# 固定范围门（复现 C 的固定球桌范围实验）

更新日期：2026-10-17。背景：C 的 TT3D-TCN 分支（`experiments/tt3d-tcn-stage-20261015`，LEGACY_20261016）在其旧入口对事件解码结果加"固定球桌范围"后处理——球心到桌面四边形有符号欧氏距离 ≤ max(2% 对角线, 4px) 才保留，公开 15 严格口径 77/38/15 → 77/20/15（81.48%），TP 全保留。

我们的现状：几何门是"毫米投影 900mm **或** 图像四边形 ±4px"双判（失败放行）。FP 取证（`README_fp.md`）曾结论"门后 FP 投影中位 4mm、毫米空间无残余分离度"——但那是**毫米空间**；"击球等悬在台面上方"的 FP 毫米投影贴近台面，**图像空间却在四边形外**。本实验验证图像空间固定范围门对现有候选栈的作用。

## 结论

1. **范围门有效且零回归**（公开 15，人工角点，容差 1–1.5%）：候选栈 **77/38/15 = 0.744 → 77/25/15 = 0.794**，清 13 个 FP，零丢命中；**留一验证**（容差在其余 14 条上选，评估留出条）留出合计 **77/26/15 = 0.790（+0.046）**，14/15 折选中 1.5%——泛化成立，非单点调参。
2. **自动角点路径（提交形态）**：系统口径 0.748 → **0.778**（77/29/15，容差 7%，零丢命中；分视角 0.756 / 0.756 / 0.817）。容差需覆盖自动角点误差（本批 15 条中误差最大 209px 的视频在 2–3% 容差下会误杀边缘触台，7% 恢复）。
3. **154 推广**（组共识角点，7/25 组可信）：纯规则 0.658 → 组门 0.670 → **+范围门 3% = 585/409/150 = 0.677（零丢命中）**；未覆盖组维持纯规则（fail-open）。
4. **机制**：77 个 TP 距四边形中位 +4.1% 对角线（均在门内）；38 个 FP 中 13 个在四边形外 ≥4px（最远 379px），其余仍在四边形内——外圈 FP 可被范围门清除，**内圈 FP（台面附近的物理事件）仍需事件模型**，与 `README_fp.md` 的判断衔接。
5. 已并入 `event_rules.py` v1.1：`range_frac` 默认 **0.07**、`range_min_px=4.0`；`range_frac=0` 关闭；需传入 table（与几何门共用 corners）。语义与 C 的 2% 容忍同源，容差按我方几何精度标定。

## 与 C 的 81.48% 的关系

C 的 77/20/15（严格口径、2% 容差）在其 TCN 候选集上取得，其 FP 分布与我们的规则候选集不同（其候选 115→97；我们清的是 38 个 FP 中的 13 个）。两组数字不能直接相减；共同结论是"图像空间固定范围"能清除毫米空间不可分的射击/击球类 FP。我们剩余 25 个 FP 中多数落在四边形内部，属台面附近的物理事件（击球/触地/触网），与 C 的幸存 FP 同性质。

## 方法

- 候选栈 = V1+F1F2F3+D2c+双判(quad4)+D3（= event_rules v1.0 默认）。
- 后处理：`d = cv2.pointPolygonTest(corners, (x,y), True)`（正=内、负=外，单位 px）；保留 `d ≥ -max(frac × 对角线, 4px)`。
- 失效放行：无角点或 `frac=0` 不动；自动角点沿用 20% 守卫（带门发射数 < 无门 20% → 回退纯规则，公开 15 触发 2 条：v000047、v000106）。
- 口径：±1 帧 / 50px 一对一；公开 15 为官方 GT（口径 A，干扰点不计）；154 为 B 候选标签 v2 + 视角映射。

## 部署建议（给 A）

- 模块 v1.1 默认 `range_frac=0.07`（适配逐视频自动角点，公开 15 零丢命中）。
- 若几何来源更可信（组投票/人工/校验过的角点），可下调：公开 15 人工角点 1–1.5% → 0.794；154 组角点 3% → 0.677。容差越小清 FP 越多，但对角点误差越敏感。
- 几何不可靠时按既有守卫传 `table=None`（门与范围门一并关闭），系统不会比纯规则更差（fail-open）。
- 与 C2 的 TCN 栈可以并存评估：本门是**后处理**，同样可作用于其事件列表（需其角点）。

## 已知限制

- 角度误差直接影响收益：自动角点误差 60–200px 的个别视频会把容差下限抬高到 4–7%；测试集几何未知，需以守卫兜底。
- 154 仅 7/25 来源组有可信组角点，其余视频未覆盖；结论以公开 15 为主、154 为规模验证。
- 公开 15 与 154 均有历史开发曝光，本实验为内层开发回归，不等于盲测。
- v000047 f63、v000066 f64 两个 TP 位于四边形外 4.6px —— 容差 0（严格四边形内）不可取，`range_min_px=4` 也刚好不够（需 1% 档）。
