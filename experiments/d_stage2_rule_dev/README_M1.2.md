## 一、取证：23 例仍漏 FN 的解剖（m12_trace）

对 V1+F1F2F3 下公开 15 剩余的 23 个有效漏报逐例追踪回放，拒绝原因分类：

| 类别 | 例数 | 说明 |
|---|---|---|
| **几何门拦截** | 8 | 发射点投影出桌 900–1800mm；其中 6 例为**近边缘透视外推爆炸**（发射点比接触点低十几像素、跨过桌面图像下缘，投影值骤爆）；2 例仅超限 2–4mm（904/902） |
| **F3 守卫拦截** | 3 | strong/far 条件未全过（如 far 差 4px、70px<100px 等边界） |
| **减速位移类** | 5–6 | 发射（y 极大）比标注帧晚 2–5 帧；标注帧处球位置其实就在标注点附近（5–16px），但 y 序列仍在下降——**"减速肩部"**被误当作仍在下落 |
| 首尾 / 未检测 | 4 | 视频首尾帧、标签帧未检测 |
| 尖峰 / 逆行 | 2–3 | 检测尖峰造出假极大、球在标注帧处于上升段等 |

**关键机制确认**（回答 M1.1 提出的"疑似检测滞后"）：

1. 位移通常是"**发射晚**"（+2..+5 帧）为主，少量反向（−4..−7）；
2. 球触台的图像特征 = **下落速度骤降**（触台瞬间减速/反向；在快速段与趋近相机效应下，y 极大被推迟到 2–5 帧之后）；
3. **几何门近边缘问题**（V1 引入的回归来源）：v000001 f58 标注点本身投影在桌内（0mm，v=1426），但发射点低 13px 就投影出桌 1226mm（透视外推在图像边缘梯度爆炸）→ 真触台被门误杀。

## 二、D2 特征：急减速回溯修正

**定义**：极大发射点（j）之前 ≤5 个达标点内，若存在减速点 k（仍在下降段 y[k]>y[k−1]，但下降速度骤降 `s_at ≤ ratio·s_prev`，s_prev∈[8, 50]，相邻输入帧距 ≤2），则把该发射**回溯修正**到 k（帧与位置都用 k 点），期间不新增任何发射。

**要点**：

- 修正后对 k 点重新做几何门判定；若不过门则不发射（顺带行为：v000095 f101 一处越界插值 FP 被去除）；
- MIN_GAP 状态用修正后的帧（efid）、位置（last_xy）继续；
- **参数判别式来自探针**（m12_probe，逐次回溯标记结果）：s_prev≤50 剔除高速段 4 例假回溯（105/78/78/320px 帧速）；回溯距离≥2 剔除 1 例 d=1 错位；ratio≤0.40 时 v000038 f112（r=0.447）与 v000117 f28 误伤（r=0.44）同时出列——**取舍下选择零回归**（r=0.45 时净收益相同但含 1 处误伤，见附件配置 D2b）。

**曾尝试并否决的变体**（留档）：

| 变体 | 结果 | 否决原因 |
|---|---|---|
| D 替换（减速点处直接发射、原极大不发） | F1 0.667 | 改变 MIN_GAP 状态引发级联，丢 5 个原命中 |
| D 附加（独立发射、独立间隔） | F1 0.661 | +7 TP 但同时 +22 FP（邻标签对错配 + 假触发） |
| D + 严格桌面邻近（出桌≤150–450mm） | 更差 | 出桌距离**不能**区分真假触发（真触台修正点与地板反弹都可能 ≤150mm） |

## 五、结论与遗留

1. **推荐配置：V1+F1F2F3+D2c（M1.2 候选）**；公开 15：V0 0.607 → 0.723（+0.116）；留一 +0.036。
2. **小样本警告**：D2c 的正样本仅 4 例，三个参数（smax50/dmin2/r40）为探针判别式所选；虽然留一无过拟合间隙、154 尺度无灾难，最终定稿仍应等 C 新轨迹（M2 四组对照）与 B 正式评估复验。
3. **遗留到下一迭代**：
   - 几何门近边缘透视爆炸（f58 一类；含 2 例仅超限 2–4mm）→ 可做"图像四边形 + 投影"双判（注意：单独放宽门会放行 6–7 个位移发射，必须与 D2 类修正**配合**再做）；
   - F3 守卫边界 3 例（far 阈值附近）→ 需与 FP 联合消融，单独放宽已证实净负；
   - 计划内 M1.3 幅度自适应、帧间触台仍未动；
   - v000037 两例（标注帧处球处上升段）、v000117 f89 等机制未明案例留档。
4. **经验教训（给后续迭代）**：任何"改动发射点/发射时机"的特征都必须评估 **MIN_GAP 状态级联**与**贪心匹配的一对一抢占**两个二阶效应——本迭代中"替换/附加"两种朴素做法的失败均源于此；"回溯修正"（MOVED 而非 ADDED/REMOVED）是目前唯一通过全部防线（FP 不恶化、零丢命中、零新增 FN）的形态。
