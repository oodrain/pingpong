# V2 规则第一迭代报告：上下文特征恢复（攻漏报）

日期：2026-10-12 ｜ 脚本：`fn_forensic.py`（31 例取证）、`r2_eval.py`（消融矩阵）、`r2_debug.py`（诊断）
数据：公开 15（官方 GT，主评估）＋ 训练 154（B 候选标签 v1，候选口径规模检验）

## 一、目标与方法

- 目标：攻 V0 的漏报（公开 15 漏 31 个有效触点；154 漏 263）。
- 流程：31 例逐例取证（轨迹窗口/极大幅度/发射列表/几何投影）→ 机制分类 → 设计三个特征 → 消融矩阵 + 留一验证 + 154 尺度检验。

## 二、取证主要发现（31 例机制分类）

| 机制 | 例数 | 说明 | 对应特征 |
|---|---|---|---|
| 强回升 / 接触处下落被压平（fall≈0，rise 大） | 6 | 接触瞬间 y 序列被量化/模糊压平，只有回升信号 | F1 |
| 延迟回升 / 慢启动下落（±1 窗幅度不足、±2 窗足够） | 5 | rise 在 j+2 才显现；fall 在 j-2 已开始 | F2 |
| 被 MIN_GAP 抑制的真实相邻触台 | 4 | 复核确认为真（含"选手连续弹球"类场景） | F3 |
| **标注帧与轨迹极大系统性差 2–5 帧** | ~7 | 牵连 FP+FN 双处罚（同一次触台记一次错+一次漏）；疑似快速段检测位置滞后 | 下一迭代 |
| 缺口 / 首尾 / 未检测 | ~8 | C 侧（等新轨迹） | — |
| 标签存疑 | 2 | 复核已标 N（如"球未触台直接落地"） | — |

另：曾疑"转播变焦破坏桌面几何"——渲染 5 个疑点帧核查后**未见几何失配**（暂排除）；但个别案例存在 775–1567mm 的异常投影距离，已记录待查。

## 三、特征（最终实现）

- **F1 强回升恢复**：rise1 ≥ 8 且后续持续上升 → 放宽下落幅度要求；
- **F2 宽窗幅度**：±2 窗口 fall2 ≥ 2 且 rise2 ≥ 2 → 放宽单帧幅度要求；
- **F3 强候选破间隔**：被 MIN_GAP 抑制时，"强形状（fall/rise 组合）+ 距上次发射 ≥ 100px + 邻域无跳点（>120px 位移）且无缺口（≤2 帧间距）"才放行；
- **接触位置插值**（关键补充）：非"基础幅度直发"的恢复型发射，用 `frac = fall1/(fall1+rise1)` 在 j/j+1 之间插值出接触帧与球心（修复"位置差 13–17px 超容差"的近失案例）；
- **扫描等价性修复**：两遍扫描严格等价官方逐帧（pass1 j≤n−3，pass2 仅 j=n−2）——修复了 F3 初版把已发射候选**重复发射**的 bug（初版 195 FP 的主因）。

## 五、结论与下一迭代

1. **推荐配置：V1+F1F2F3（V2 第一迭代候选）**；V1+F1F2 作为"更简单、精度略高"的备选（两者差异很小，最终定稿待接入 C 新轨迹 + B 正式评估后拍板）；
2. **下一迭代重点：接触时刻系统偏差**——"标注帧与轨迹极大差 2–5 帧"类有**双重价值**（每组 = 转化 1 FP + 1 FN 为 TP），疑似快速段检测位置滞后/插值估计问题；
3. 等 C 新轨迹接入复跑（去化缺口/跳点类）；等 B 口径与划分；154 的几何门推广依赖自动桌面方案。
