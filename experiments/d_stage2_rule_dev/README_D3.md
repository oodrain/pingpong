## 一、破案：上行族的物理机制（0° 远半台触台）

154 剩余漏报中最大的未解块 = "标注帧上行" 29 例（0° 占 24）。取证结论（渲染对照 + 桌框锚定，00_001 f92）：

- **标注帧处球确实贴台面**（标注与检测位置差 2px、conf 0.95），是**真实触台**；
- 但图像 y 序列在标注帧处**单调下降**（球在"上升"）——**球向远处飞（深度↑，图像 y↓）与下落（高度↓，图像 y↑）在 0° 视角下相互抵消**，V 形触台信号被完全掩蔽，没有任何 y 极大；
- 对照同视频 f62 的正常近台触台（y 极大清晰可见），机制成立。

**可用签名**：y 序列在掩蔽触台处留下"**上升速度浅坑**"——单调上升中速度骤减（如 −15→−1→−25 像素/帧），
**坑底即触台**。24/29 例验证成立：坑底距标注点 1–16px（中位 ≈2px）、帧差 ±1 内。

## 二、D3 特征定义

在"单调上升但速度骤减"的点 k 发射（**附加模式**，不改变主扫描 MIN_GAP 状态）：

```
y[k] < y[k-1] 且 y[k+1] < y[k]        （两侧单调上升）
ρ_in = y[k-1]-y[k]，ρ_prev = y[k-2]-y[k-1]，ρ_out = y[k]-y[k+1]
ρ_prev ≥ 3 且 ρ_out ≥ 3               （两侧运动充分）
ρ_in ≤ 0.45·ρ_prev 且 ρ_in ≤ 0.45·ρ_out（速度骤减后骤增）
相邻输入帧距 ≤ 2                       （无缺口）
发射点与主发射及前一次 D3 发射间隔 ≥ 10
```
