# 154条视频裁决汇总候选标签 v1

本目录是 B 本阶段的数据整理交付物，由初标、独立复核和第三复核非破坏性汇总生成；原始 `labels/` 不修改。它是后续数据划分、抽查、训练和统一评估的候选输入，不等同于官方 GT，也不表示项目最终标签已经冻结。

- `candidate_events.jsonl`：逐触台候选点总表。
- `candidate_by_video.jsonl`：154条视频分组结果；固定训练/开发划分后按对应子集读取。
- `excluded_uncertain.jsonl`：第三复核仍为纯疑难的条目，本版候选标签不纳入。
- `rejected_no_bounce.jsonl`：第三复核确认非触台的条目。
- `duplicate_candidates.jsonl`：同一容差窗口内的重复候选检查结果；为空仅表示未发现此类重复，不代表标签已完成最终验收。
- `merge_report.json`：数量、汇总口径和完整性报告。

汇总匹配阈值沿用评测容差：帧号前后1帧、欧氏位置距离50像素，并执行一对一匹配。该阈值用于形成阶段候选结果，不是对真实触台正确性的额外证明。
