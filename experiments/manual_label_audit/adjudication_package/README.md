# 第三复核裁决包

本目录用于处理初标与复核未达到“帧差不超过1帧且球心距离不超过50像素”的争议事件。共139条，工具稳定分配为A 35条、B 35条、C 35条、D 34条；每条不会分给其初标者或原复核者。

## 使用方式

1. 从仓库`tools/`下载并完整解压`pingpong-annotation-local-20261009.zip`。
2. 启动工具并选择自己的A/B/C/D成员编号。
3. 点击“第三复核/裁决”，裁决包选择本目录。
4. 数据根目录选择本机同时包含A、B、C、D四个数据文件夹的目录。每个成员目录下须有原始`videos`和配套`json`。
5. 工具只显示分配给当前成员的任务。完成前隐藏初标和复核标签；按C完成后，才可按H对照。

前期生成的A-B、B-C、C-D、D-A短片带有人工标记，不适合盲审，现已从分发包删除。Git默认也不会提交视频。第三复核必须读取本地干净原视频；原视频和对象JSON通过团队已有数据渠道传递，不上传Git仓库。

## 判断口径

- 确认触台：定位准确帧，左键点球心，按Enter保存。二次弹跳、桌边反弹、部分遮挡等只要能确认触台并能标出球心，也统一按触台保留。
- 不是触台：按X。
- 纯粹疑难：只有无法判断是否触台，或无法可靠确定触台帧/球心时，才按U并填写原因。
- 最后按C确认本条完成。本轮第三复核作为最终判断，不再安排第四人。
- 完成后若发现错误，按E填写修改原因即可重新编辑；旧结果自动进入本机历史，修改后须再次按C完成。

汇总时保留全部`confirmed`，`no_bounce`不生成触台点，只有`uncertain`从当前训练标签中剔除并单独留档。

## 文件与提交

- `decision_template.jsonl`：139条固定裁决输入，所有人必须使用同一版本，不自行修改。
- `third_review/A.jsonl`至`D.jsonl`：各成员自动保存的结果。
- `third_review/history/`、`_third_review_cache/`和`_third_review_work/`：本机历史或缓存，不提交。
- 原`labels/.../initial`和`review`不会被第三复核工具修改。

为保持盲审，每个人只把自己的`third_review/<成员>.jsonl`提交到自己的分支；四个人全部完成前不要将这些结果合并进公共主分支。全部完成后再统一合并并生成最终标签。
