# 数据需求清单 v1（D → 组长/B/C，草稿待发）

依据：错误分类 v1（技术归因）+ v2（人工复核 185 张）+ 几何约束第一版对照（见同目录《几何约束第一版报告》）

## 1. 缺什么

- **① 154 条候选标签的完整性核对**：采样复核发现 33 条"误报"实际是真触台（其中 28 条附近无任何标签），另有 2 条公共 15 的漏报被评为"标签存疑"。全量外推：候选标签 v1 可能缺失约 150+ 个真实落点。
- **② C 侧轨迹质量问题清单**：154 中约 146 个错误事件与轨迹/检测直接相关（跳点 61、缺口附近 56、未检测 16、低置信 5、邻居缺口 8）。
- **③ 154 的分视角映射**：交付清单 `angle=unknown`，分视角评估需要可信映射。
- **④（条件性）154 的桌面几何**：训练包仅有桌框（粗筛），几何约束若要在 154 推广，需要可靠桌面信息（自动获取或抽查补标）。

## 2. 解决哪类错误

- ① → "假误报"（规则被冤枉）+ 真实的漏标 → 直接修正误报率口径与评估基准；
- ② → 误报/漏报中的检测类错误（跳点/缺口/未检测占 154 总错误约 23%）；
- ③ → 分视角评估与靶向改进（0° 是公开集最弱视角，154 需要知道同样的信息）；
- ④ → 几何规则能否从公开 15 推广到 154（目前只在公开 15 验证：全量 +0.045、留一验证 +0.036）。

## 3. 为什么现有数据不足

- 154 候选标签 v1 明确排除了 37 条疑难，且真实落点仍有缺失（上条①证据）；复核只采样了 111 张，**需要 B 对全量 T 类案例定论**；
- 轨迹缺失 3362 帧、跳点/缺口是检测/解码层面的问题，标注无法弥补；
- 训练包桌框在透视下不能准确表示桌面边界，不能直接当几何使用（方案 §4.1 已写明"只能粗筛"）。
